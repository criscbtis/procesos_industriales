01. Diagrama del Sistema

Descripción del Diagrama:

En esta sección se representa la arquitectura de componentes del invernadero inteligente. El microcontrolador central procesa la información recibida desde los sensores ambientales y determina la activación de los actuadores correspondientes para mantener las condiciones óptimas del cultivo.

02. Código de Control

//L3.0
//incluimos las librerias que se utilizaran

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <DHT.h>

//pines que usaremos
int pin = 3;
int ventilador = 6;

DHT dht(pin, DHT11); //pin que se usara y tipo de sensor dht
LiquidCrystal_I2C lcd(0x27, 16, 2); //0x27,16,2

void setup() {
  pinMode(ventilador, OUTPUT);
  dht.begin();
  lcd.init();
  lcd.backlight();
  lcd.clear();
}

void loop() {
  //leemos los datos de los sensores
  int h = dht.readHumidity();
  int t = dht.readTemperature();
  
  if (isnan(h) || isnan(t)) { //verificamos si los valores no son numeros
    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("error de lectura"); //avisamos al usuario que hubo un error
  }
  else {
    lcd.clear(); //limpiamos la pantalla

    lcd.setCursor(0, 0); //le decimos a la pantalla que lo va a imprimir en la fila 0 y columna 0
    lcd.print("temp:"); //imprimimos la temperatura
    lcd.print(t);
    lcd.print("c"); //el resultado es temp:(valor leido por el sensor)c

    lcd.print(" hum:"); //imprimimos la humedad
    lcd.print(h);
    lcd.print("%"); //el resultado es hum:(valor leido por el sensor)%
  }

  if (t > 30) { //si la temperatura supera los 30°C se enciende el ventilador
    digitalWrite(ventilador, 1);
  }
  else { 
    digitalWrite(ventilador, 0);
  }

  delay(1000);
}

Descripción del Código:

Este programa utiliza un sensor DHT11 para monitorear la temperatura y la humedad relativa en tiempo real. Muestra estas lecturas en una pantalla LCD I2C y, en caso de fallo en el sensor, despliega un mensaje de error. Si la temperatura supera un umbral establecido, activa un ventilador a través del pin digital 6 para regular las condiciones ambientales.
