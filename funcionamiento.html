01. Diagrama del Sistema

Descripción del Diagrama:

En esta sección se representa la arquitectura de componentes del invernadero inteligente. El microcontrolador central procesa la información recibida desde los sensores ambientales y determina la activación de los actuadores correspondientes para mantener las condiciones óptimas del cultivo.

02. Código de Control

#include <LiquidCrystal_I2C.h>
#include <Wire.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);
int bomba_agua = 13;

void setup() {
  pinMode(bomba_agua, OUTPUT);
  lcd.init();
  lcd.backlight();
  lcd.clear();
}

void loop() {
  digitalWrite(bomba_agua, LOW);
  int valor = analogRead(A0);
  
  lcd.setCursor(0, 0);
  lcd.print(valor);
  delay(100);
  
  if (valor < 200) {
    digitalWrite(bomba_agua, HIGH);
  }
}

Descripción del Código:

Este programa controla la activación de una bomba de agua conectada al pin 13 mediante la lectura analógica de un sensor conectado al pin A0. Además, utiliza una pantalla LCD I2C (dirección 0x27) para mostrar en tiempo real la lectura obtenida. Si el valor analógico es menor a 200, la bomba de agua se activa.
