01. Diagrama del Sistema

Descripción del Diagrama:

En esta sección se representa la arquitectura de componentes del invernadero inteligente. El microcontrolador central procesa la información recibida desde los sensores ambientales y determina la activación de los actuadores correspondientes para mantener las condiciones óptimas del cultivo.

02. Código de Control

// Control Automatizado - Invernadero Inteligente
#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT11
#define PIN_BOMBA 8
#define PIN_VENTILADOR 9

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  pinMode(PIN_BOMBA, OUTPUT);
  pinMode(PIN_VENTILADOR, OUTPUT);
  dht.begin();
}

void loop() {
  float temp = dht.readTemperature();
  int humedadSuelo = analogRead(A0);

  // Lógica de control de temperatura
  if (temp > 30.0) {
    digitalWrite(PIN_VENTILADOR, HIGH);
  } else {
    digitalWrite(PIN_VENTILADOR, LOW);
  }

  delay(1000);
}
